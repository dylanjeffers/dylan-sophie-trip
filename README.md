# Dylan & Sophie trip map

Public family map for the Spain + Nice trip (Nov 2026). Static Leaflet page + `stops.json`, with photos uploaded from our phones to Vercel Blob through `api/upload.js` and listed by `api/photos.js` (uploads need the `UPLOAD_PASSCODE` env var).

`stops.json` is generated from the private planning map; booking codes and logistics are left out.
